- **도메인 규칙 고정** (`README.md` / `docs/requirements_analysis.md` / `tasks/0.setting.md`):  
  - BMI = kg / (m)², m = cm/100  
  - 분류: ≤18.5 저체중(100), 18.5<BMI<23 정상(200), 23≤BMI<25 과체중(300), BMI≥25 비만(400)  
  - 연령대 `[a,a+10)`, a∈{20,30,40,50,60,70}  
  - `weight==0` → 동 연령대 유효 체중 평균 보정 (기 구현)  
  - `height==0` → 동 연령대 유효 키(cm) 평균 보정 (**신규**, weight와 대칭)  
  - 파이프라인 순서: **load → imputeWeight → imputeHeight → computeBmi → aggregate**  
- **테스트**: `shealth.dat` 전체 의존 금지. 임시 CSV fixture 유지. 각 단계 후 `cmake --build . && ctest --output-on-failure` Green. Red 상태에서 대량 리팩토링 금지.  
- **스펙 vs 레거시**: Activity 3 TC 22건 **삭제·약화 금지**. 신규 TC는 `docs/requirements_analysis.md` §5.6 시나리오 26~30 정렬.  
- **범위 외**: Activity 5(회고·발표), README 외 신규 요구, CSV 포맷 변경.
