### [T] 섹션별 작성 요구 (산출물 목차)

#### 1) 처리 단계·분류별 비즈니스 규칙 표

최소 다음 표를 포함한다.

| 구분 | 스펙(README) | 레거시 구현(해당 시) | C++ 구현 시 유의 |
|------|--------------|----------------------|------------------|
| CSV 파싱 | … | … | … |
| 연령대 `[a,a+10)` | a∈{20,30,…,70} | … | … |
| weight=0 보정 | 동일 연령대 유효 체중 평균 | … | ageCount=0 시 |
| BMI 계산 | kg/(m)², m=cm/100 | … | height=0 |
| 저체중 | BMI≤18.5, type 100 | … | … |

| 과체중 | 23≤BMI<25, type 300 | … | … |
| 비만 | BMI≥25, type 400 | `>25`만 비만 처리 등 | **BMI=25** |
| 비율 산출 | 연령대별 4분류 %, 합≈100% | … | sum=0 |

#### 2) 수치·문자열 처리 주의점

다음 항목을 번호 목록으로 정리한다 (Gilded Rose의 `name` 문자열 분기에 대응).

- `split(line, ',')` — 빈 줄, 컬럼 수 부족, `tokens.empty()` 시 루프 중단  
- `std::stoi` / `std::stod` — 잘못된 형식 시 예외 (`invalid_argument`, `out_of_range`)  
- 부동소수점: `weight == 0.0`, BMI 경계는 `EXPECT_NEAR` / ε 비교 권장  
- 연령 구간: `age >= a && age < a+10` — 19대·80대 등 **집계 제외** 명시  
- 파일 경로: 존재하지 않을 때 `calculateBmi` 반환값·stderr 동작  
- 공개 API 변경 금지: `calculateBmi`, `getBmiRatio` 시그니처 유지 원칙

#### 3) 예외·경계값 조건

표 + 짧은 설명:

| 영역 | 경계·예외 | 기대 동작(스펙 합의안) | 레거시 리스크 |
|------|-----------|-------------------------|---------------|
| BMI | 18.5, 23, 25, 25.0±ε | … | BMI=25 미집계 |
| 연령 | 19,20,29,30,69,70,71 | … | 구간 밖 레코드 |
| 체중 | 0, 양수 | … | ageCount=0 |
| 키 | 0, 양수 | (신규) height 보정 | 0 나눗셈 |
| 파일 | 없음, 헤더만, 빈 줄 | … | return 0 |
| 배열 | count>10000 | … | 고정 배열 상한 |
| 비율 | 연령대 인원 0 | … | 0 나눗셈 |

#### 4) README 4단계 신규·확장 요구사항

각 기능에 대해 **입력·출력·기존 API와의 관계·테스트 포인트**를 명세한다.

1. SRP 리팩토링 — 책임 분리 범위(파일 I/O / 보정 / BMI / 통계)  
2. 특정 연령대 BMI 분포 비율 — `getBmiRatio`와 중복·대체 관계  
3. **height==0** — weight=0과 동일 패턴의 연령대 평균 보정 (감소율 2배에 해당하는 **대칭 신규 규칙**)  
4. 정상 BMI 사용자 목록 조회 — 반환 타입·필터 조건 (18.5<BMI<23)  
5. 전체 사용자 대비 각 BMI 범주 비율 — 연령대 무관 집계

#### 5) Google Test 시나리오 목록

- `TEST_F(SHealthBMITest, …)` / `MethodName_State_ExpectedResult` 네이밍  
- Given-When-Then 주석 1줄  
- 최소 **25개** 번호 시나리오 (BMI 계산 5, 보정 5, 분류·경계 8, 비율·API 4, 예외·파일 3)  
- 임시 CSV fixture 사용 — `shealth.dat` 전체 의존 최소화  
- 레거시 버그(BMI=25)는 **스펙 기준 실패 테스트**로 명시

예시 형식:

```
1. CalculateBmi_KnownWeightHeight_ReturnsExpectedBmi — G:70kg/170cm W:calculate W:BMI≈24.22
2. …
```
