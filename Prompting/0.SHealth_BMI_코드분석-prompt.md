## 프로젝트 구조 (변경 시 이 레이아웃 유지)
```
CMakeLists.txt
shealth.dat                    # 입력 데이터 (id,age,weight,height CSV)

```

## 도메인 규칙 (절대 준수)

### 입력 데이터
- CSV 형식: `id,age,weight,height` (첫 줄 헤더 스킵)
- `weight`, `height` 단위: kg, cm
- `weight == 0.0` → **같은 연령대**의 유효 체중(weight ≠ 0) 평균으로 보정
- 연령대 구간: `[a, a+10)` — `a ∈ {20, 30, 40, 50, 60, 70}` (README·기존 코드 기준)

### BMI 계산
```
BMI = weight(kg) / (height(m))²
height(m) = height(cm) / 100.0
```

### BMI 분류 (README 스펙 — 테스트가 진실의 원천)
| 구간 | 분류 | `getBmiRatio` type 코드 |
|------|------|-------------------------|
| BMI ≤ 18.5 | 저체중 (underweight) | 100 |
| 18.5 < BMI < 23 | 정상 (normal) | 200 |
| 23 ≤ BMI < 25 | 과체중 (overweight) | 300 |
| BMI ≥ 25 | 비만 (obesity) | 400 |

- 경계값(18.5, 23, 25)은 **반드시** 단위 테스트로 고정한다.
- 레거시 구현과 스펙이 다르면(예: `bmis[i] > 25`) 테스트를 먼저 작성·합의한 뒤 코드를 수정한다.

### 공개 API (리팩토링 시 시그니처 유지)
```cpp
class SHealth {
public:
    int calculateBmi(const std::string& filename);  // 로드·보정·BMI·통계 계산, 처리 건수 반환
    double getBmiRatio(int ageClass, int type);     // ageClass: 20~70, type: 100/200/300/400
};
```
- `calculateBmi` / `getBmiRatio`의 **시그니처와 반환 의미**를 바꿀 때는 테스트·main(`SHealthBMI.cpp`)을 함께 갱신한다.
- `split`은 private 헬퍼; 외부에서 직접 호출하지 않는다.

### 금지·주의
- `shealth.dat` 실제 파일 포맷·컬럼 순서를 바꾸지 않는다.
- 전역 변수 추가 금지 (README 실습 목표: 하드코드·전역 제거).
- `calculateBmi` 한 함수에 파일 I/O·보정·BMI·통계를 무한정 쌓지 않는다 — 테스트 Green 유지하며 단계적 분리.
- 연령대·BMI 임계값·type 코드(100/200/300/400)를 테스트 없이 변경하지 않는다.

### 허용 (README 기준)
- 내부 구현에서 STL(`std::vector`, `std::map`, 알고리즘 등) 사용 가능.
- 고정 크기 배열(`ages[10000]` 등)을 컨테이너로 교체 가능 — **동작·테스트 통과**가 전제.

## 테스트 규칙

### 스타일
- **Given-When-Then** 주석으로 의도를 명시한다.
- `TEST_F` + fixture 클래스 사용 (`class SHealthBMITest : public ::testing::Test`).
- 테스트 이름: `MethodName_State_ExpectedResult` (예: `ClassifyBmi_AtBoundary18_5_IsUnderweight`).
- 한 테스트 = 한 가지 검증 (Arrange-Act-Assert).

### 필수 커버리지 영역
1. **BMI 계산**: 알려진 weight/height → 기대 BMI (소수 허용 오차 `EXPECT_NEAR`, `1e-4` 등).
2. **체중 0 보정**: 동일 연령대 평균 적용 여부.
3. **BMI 분류**: 저체중/정상/과체중/비만 4구간.
4. **연령대별 비율**: `getBmiRatio(ageClass, type)` — 비율 합 ≈ 100%.
5. **예외·엣지**: 파일 없음, 빈 파일, 해당 연령대 유효 체중 0건, `ageCount == 0` 보정 등.

### 경계값 (반드시 포함)
| 항목 | 경계 케이스 |
|------|-------------|
| BMI | 18.5, 18.5+ε, 23, 25 |
| 연령 | 19/20, 29/30, 69/70, 70/71 (구간 `[a,a+10)` 경계) |
| 체중 | 0(누락), 양수 |
| 키 | 0(향후 보정 기능), 정상 cm 값 |
| 비율 | 연령대 인원 0명, 1명 |

### 테스트 데이터
- 단위 테스트는 **작은 인메모리/임시 CSV**로 격리한다 (`TEST_F` SetUp에서 임시 파일 생성 권장).
- `shealth.dat` 전체에 의존하는 테스트는 통합 테스트로 분리하고, 수치는 스냅샷보다 **도메인 규칙**으로 검증한다.

## 리팩토링 규칙
1. **테스트가 전부 Green일 때만** 리팩토링한다. Red → Green → Refactor 순서.
2. 리팩토링 PR/커밋 단위: 네이밍 → 매직 넘버 상수화 → 함수 추출 → 중복 제거 → SRP 분리.
3. 매직 넘버는 명명 상수·enum으로 치환:
   - `18.5`, `23`, `25` (BMI 임계값)
   - `100`, `200`, `300`, `400` (type 코드)
   - `20`, `30`, … `70` (연령대), `10` (구간 폭)
   - `100.0` (cm→m 변환)
4. `getBmiRatio`의 age×type if-else 사다리는 맵/테이블/enum 기반으로 단계적 축소.
5. 기능 추가(README 4단계) 시 기존 API를 깨지 않고 **새 메서드** 또는 명시적 확장으로 추가:
   - 특정 연령대 BMI 분포 비율
   - height == 0 평균 보정
   - 정상 BMI 사용자 목록
   - 전체 대비 범주 비율
6. `main`은 얇게 유지; 비즈니스 로직은 `SHealth`(또는 분리된 클래스)에 둔다.

## 코드 품질
- C++17 관용구 사용 (`std::optional`, structured binding, `enum class` 등) — 과도한 템플릿 메타프로그래밍 금지.
- RAII, `const` 정확성, 의미 있는 이름 (`ageClass`, `bmiCategory` 등).
- 불필요한 주석·보일러플레이트 테스트 금지.
- 변경 범위는 요청·실패 테스트에 필요한 최소 파일만.
