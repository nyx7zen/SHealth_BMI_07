## 3. 실행 결과 요약

### 3.1 제약·전제 (실행 시 준수)

| 제약 | 내용 |
|------|------|
| 공개 API | `calculateBmi`, `getBmiRatio` 시그니처·반환 의미 **유지** |
| 도메인 | BMI 18.5/23/25, 연령 `[a,a+10)`, type 100~400, CSV 포맷 고정 |
| 진행 | 단계마다 `cmake --build` && `ctest` Green 후만 다음 단계 |
| God Method | README 4단계는 **신규 public 메서드** — `calculateBmi`에 누적 금지 |

### 3.2 실행 순서

**테스트 Green → BMI=25 스펙 수정 → 상수화 → 함수 추출 → 테이블화 → SRP·신규 API**

`docs/code_quality_report.md` Top 5와 로드맵 `CQ#` 열(1~5)이 1:1 매핑된다.

### 3.3 16단계 실행 로드맵 요약

| Phase | 단계 | 실행 내용 |
|-------|------|-----------|
| A | 0–3 | `FAIL()` 제거, fixture, BMI=25 Red→Green, 경계 TC |
| B | 4–7 | `classifyBmi` 추출, `constexpr`, 0 나눗셈 가드, 연령 필터 중복 제거 |
| C | 8–12 | `array[6][4]` 테이블, `getBmiRatio` 1줄 조회, SRP 1차, `enum class`, `vector` |
| D | 13–15 | height 보정, `getNormalBmiUsers` 등, 통합·문서화 |

### 3.4 리팩토링 대상 스멜 (실행 전·앵커)

| 스멜 | 위치 | 실행 단계 |
|------|------|-----------|
| BMI=25 미집계 (`> 25`) | `SHealth.cpp` L71 | 2 |
| God Method (~103줄) | L6–108 | 10, 13–14 |
| 연령대 루프 3회 | L29–48, L56–107 | 7, 8 |
| `a==20…70` 저장 6×4줄 | L76–106 | 8 |
| `getBmiRatio` 24-way | L111–136 | 9 |
| parallel array + 24 `double` | `SHealth.h` L12–25 | 8, 12 |
| `FAIL()` only | `SHealthBMITest.cpp` L4–6 | 0 |

### 3.5 Phase별 검증

모든 Phase 공통:

```bash
mkdir -p build && cd build
cmake ..
cmake --build .
ctest --output-on-failure
```

Windows: `build`에서 동일 (`ctest -C Debug` 필요 시 명시).
