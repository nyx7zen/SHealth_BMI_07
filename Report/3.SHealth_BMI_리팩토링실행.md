## 3. Before → After 요약

| 구분 | Before (레거시) | After (1차 리팩토링) |
|------|-----------------|----------------------|
| `calculateBmi` | ~102줄 God Method, 4단계 인라인 | Facade 4줄 + private 파이프라인 |
| BMI 비만 경계 | `bmis[i] > 25` (BMI=25 누락) | `classifyBmi` → `>= 25` Obesity |
| 0 나눗셈 | `sum/ageCount`, `*100/sum` 미방어 | `validWeightCount==0`, `memberCount==0` 가드 |
| 비율 저장 | 24개 `double` 멤버 + `a==20…70` 6분기 | `std::array<array<double,4>,6> bmiRatios_` |
| `getBmiRatio` | 24-way if-else (L111~136) | 인덱스 lookup (~5줄) |
| 테스트 | `FAIL()` only | `TEST_F` 13건, 임시 CSV fixture |

## 5. 스펙·버그 수정

| 이슈 | 수정 |
|------|------|
| BMI = 25.0 미집계 | `classifyBmi`: `bmi >= kBmiOverweightMax` → Obesity |
| `ageCount == 0` 보정 | `imputeMissingWeightsForBand` — 유효 체중 없으면 스킵 |
| `sum == 0` 집계 | `aggregateRatiosForBand` — 인원 0이면 비율 0 초기화 |
| `count > 10000` | `loadRecordsFromCsv` — `kMaxRecordCount` 상한 |
