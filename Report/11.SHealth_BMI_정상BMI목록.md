## 3. 신규 API

| 메서드 | 입력 | 출력 | 필터 |
|--------|------|------|------|
| `getNormalBmiUserIds() const` | (내부 상태, `calculateBmi` 후) | `std::vector<int>` | `classifyBmi(bmi) == Normal` → **18.5 < BMI < 23** |

- `getBmiRatio`와 책임 분리: 연령대별 **비율** vs 전 사용자 **id 목록**
- God Method(`calculateBmi`)에 필터 로직 누적하지 않음 — 조회 전용 public 메서드
