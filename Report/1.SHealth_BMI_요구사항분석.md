## 3. 핵심 결과 요약

### 3.1 도메인 파이프라인

1. CSV 로드 (`id,age,weight,height`)  
2. 연령대별 `weight==0` → 동일 대 유효 체중 평균 보정  
3. BMI = kg / (m)²  
4. 연령대 `[20,30,…,70)` 별 4분류 비율 → `getBmiRatio(ageClass, type)`

### 3.2 스펙 vs 레거시 (반드시 TDD로 고정)

| 이슈 | README | 레거시 `SHealth.cpp` |
|------|--------|----------------------|
| 비만 경계 | BMI **≥** 25 | `bmis[i] > 25` (71행) → **BMI=25 미집류** |
| weight 보정 | 연령대 평균 | `ageCount==0` 시 0 나눗셈 (44행) |
| height=0 | 4단계 신규 보정 | 미구현, BMI 계산 시 0 나눗셈 |
| 연령대 비율 | 4분류 합 ≈ 100% | `sum==0` 시 0 나눗셈 (77행) |

### 3.3 BMI 분류·type 코드

| 분류 | 조건 | type |
|------|------|------|
| 저체중 | ≤ 18.5 | 100 |
| 정상 | 18.5 < BMI < 23 | 200 |
| 과체중 | 23 ≤ BMI < 25 | 300 |
| 비만 | ≥ 25 | 400 |
