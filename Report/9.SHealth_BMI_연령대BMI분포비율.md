## 3. F2 완료 정의 — 단일 소스 아키텍처

README 「추가」는 신규 API 중복이 아니라, 리팩토링 후 **집계·조회 단일 경로** 확립을 의미한다.

| 역할 | 메서드 | 데이터 |
|------|--------|--------|
| 쓰기 | `aggregateRatiosForBand` → `aggregateRatiosByAgeBand` | `bmiRatios_[bandIndex][categoryIndex]` |
| 읽기 | `getBmiRatio(ageClass, type)` | 동일 테이블 lookup (`ageClassToIndex`, `typeCodeToCategoryIndex`) |

```
calculateBmi → … → aggregateRatiosByAgeBand()  // bmiRatios_ 갱신
getBmiRatio(age, type)                         // bmiRatios_ 조회만
```

24-way if-else 사다리는 제거된 상태이며, 연령대별 4분류 합은 약 100%가 된다.

## 4. 도메인 규칙 (연령대별 비율)

| 항목 | 규칙 |
|------|------|
| 연령대 | `[a, a+10)`, a ∈ {20, 30, 40, 50, 60, 70} |
| 분류 | ≤18.5 저체중(100), 18.5<BMI<23 정상(200), 23≤BMI<25 과체중(300), ≥25 비만(400) |
| 비율 | 해당 연령대 인원 중 분류별 `count / memberCount × 100` |
| type 코드 | 100, 200, 300, 400 — 잘못된 age/type → `0.0` |
