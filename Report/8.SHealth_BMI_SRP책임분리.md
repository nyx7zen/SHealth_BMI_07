## 3. SRP 파이프라인 (Before → After)

### Before

`calculateBmi`가 weight 보정·BMI 계산·집계를 직접 호출. height 보정 단계 없음.

```
loadRecordsFromCsv → imputeMissingWeightsByAgeBand → computeAllBmis → aggregateRatiosByAgeBand
```

### After (Facade)

```
loadRecordsFromCsv
  → imputeMissingWeightsByAgeBand()
  → imputeMissingHeightsByAgeBand()   // 신규 (weight와 대칭)
  → computeAllBmis()
  → aggregateRatiosByAgeBand()
```

`calculateBmi`는 위 5단계 **오케스트레이션만** 수행 (God Method 해소 유지).

---

## 4. 책임 분리 매핑

| 단계 | private 메서드 | 책임 |
|------|----------------|------|
| 1 | `loadRecordsFromCsv` | CSV I/O, 배열 적재 |
| 2 | `imputeMissingWeightsByAgeBand` / `imputeMissingWeightsForBand` | 연령대별 weight=0 보정 |
| 3 | `imputeMissingHeightsByAgeBand` / `imputeMissingHeightsForBand` | 연령대별 height=0 보정 (weight 대칭) |
| 4 | `computeAllBmis` / `computeBmi` | BMI 산출 |
| 5 | `aggregateRatiosByAgeBand` / `aggregateRatiosForBand` | 연령대별 4분류 비율 집계 |
| Facade | `calculateBmi` | 파이프라인 순서 보장·`recordCount_` 반환 |
| Query | `getBmiRatio` | 집계 테이블 `bmiRatios_` 조회 |
