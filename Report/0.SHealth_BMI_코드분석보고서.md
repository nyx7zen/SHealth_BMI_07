## 1. 개요

삼성 헬스 시나리오를 모델링한 C++17 레거시 프로젝트입니다. CSV(`shealth.dat`)에서 사용자 건강 데이터를 읽어 BMI를 계산하고, 연령대(20·30·40·50·60·70대)별 저체중/정상/과체중/비만 **비율(%)**을 산출합니다.

### 1.1 비즈니스 요구사항 (README 기준)

| 항목 | 규칙 |
|------|------|
| 입력 | `id`, `age`, `weight(kg)`, `height(cm)` |
| BMI | `weight / (height(m))²`, `height(m) = height(cm) / 100` |
| 누락 체중 | `weight == 0` → 동일 연령대 유효 체중의 평균으로 대체 |
| 저체중 | BMI ≤ 18.5 |
| 정상체중 | 18.5 < BMI < 23 |
| 과체중 | 23 ≤ BMI < 25 |
| 비만 | BMI ≥ 25 |

### 1.2 데이터 규모

- `shealth.dat`: 약 4,823행 (헤더 1행 + 데이터 약 4,822건)
- 현재 코드 상한: 고정 배열 `10000` — 현 데이터량에서는 여유 있음

### 2.1 공개 API

| 메서드 | 역할 | 반환 |
|--------|------|------|
| `calculateBmi(filename)` | 파일 로드 → 체중 보정 → BMI 계산 → 연령대별 통계 | 처리 건수 `count` |

## 3. 처리 흐름 분석

`calculateBmi` 한 함수가 다음을 **순차·단일 책임 없이** 수행합니다.

```
[파일 열기] → [CSV 파싱·배열 저장]
    → [연령대별 weight=0 평균 보정]
    → [BMI 계산]
    → [연령대별 4분류 집계·비율 저장]
    → count 반환
```

### 3.1 연령대 구간

- 구간: `[a, a+10)` where `a ∈ {20, 30, 40, 50, 60, 70}`
- 예: 20대 = age 20 이상 30 미만

### 3.2 체중 0 보정 로직

1. 각 연령대 `a`에 대해 `weight ≠ 0`인 레코드만 합산 → `sum`, `ageCount`
2. 같은 구간에서 `weight == 0`인 레코드에 `sum / ageCount` 대입

### 3.3 BMI 분류 (현재 구현)

```cpp
if (bmis[i] <= 18.5)           underweight++;
else if (bmis[i] > 18.5 && bmis[i] < 23)  normalweight++;
else if (bmis[i] >= 23 && bmis[i] < 25)   overweight++;
else if (bmis[i] > 25)          obesity++;   // ← 스펙과 불일치 가능
```

## 4. 코드 스멜 (Code Smells)

### 4.1 심각도 높음

| # | 스멜 | 위치 | 설명 |
|---|------|------|------|
| 1 | **God Method** | `calculateBmi` | I/O, 파싱, 보정, BMI, 통계가 한 함수에 집중 (약 100줄) |
| 2 | **스펙 불일치** | `SHealth.cpp:71` | 비만 조건이 `> 25` — README는 `≥ 25` |
| 3 | **미분류 BMI** | `SHealth.cpp:65-73` | BMI == 23, 25 등 경계에서 일부 분기 누락 가능 (`> 18.5 && < 23` 등으로 23.0·25.0 처리 모호) |
| 4 | **0으로 나누기** | `SHealth.cpp:44, 77-105` | `ageCount == 0` 또는 연령대 `sum == 0` 시 미정의 동작 |
| 5 | **테스트 부재** | `SHealthBMITest.cpp` | `FAIL()`만 있어 회귀 방지 불가 |

### 4.2 심각도 중간

| # | 스멜 | 위치 | 설명 |
|---|------|------|------|
| 6 | **Data Clumps / 배열 남용** | `SHealth.h` | `ages`, `weights`, `heights`, `bmis` + 24개 비율 멤버 — 구조체·맵으로 응집 가능 |
| 7 | **Magic Number** | 전역 | `18.5`, `23`, `25`, `100/200/300/400`, `20~70`, `10000` |
| 8 | **중복 코드 (Duplicated Code)** | `calculateBmi` 76-106행, `getBmiRatio` 전체 | 연령대×분류별 if-else 사다리 반복 |
| 9 | **Poor Naming** | `sum`(인원 수), `type` | 의미 불명확 (`memberCount`, `BmiCategory` 등 권장) |
| 10 | **경계 미검증** | 파싱 루프 | `count`가 10000 초과 시 버퍼 오버플로, `stoi`/`stod` 예외 미처리 |

### 4.3 심각도 낮음

| # | 스멜 | 설명 |
|---|------|------|
| 11 | **Dead/미사용 ID** | CSV `id` 컬럼을 읽지 않음 (`tokens[0]` 무시) |
| 12 | **C 스타일 I/O** | `main`에서 `printf` 사용 (프로젝트 일관성) |
| 13 | **불필요한 `file.close()`** | RAII(`ifstream` 소멸)로 충분 |
| 14 | **height=0 미처리** | README 4단계 요구(키 평균 보정) 미구현 |

## 5. 스펙 vs 구현 차이 (상세)

### 5.1 BMI 25 경계

| 구분 | 비만(BMI=25) 처리 |
|------|-------------------|
| README | 25 **이상** → 비만 |
| 현재 코드 | `bmis[i] > 25` → BMI=25.0은 **어느 분류에도 포함되지 않을 수 있음** |

### 5.2 BMI 23 경계

| 구분 | 과체중(BMI=23) 처리 |
|------|---------------------|
| README | 23 **이상** → 과체중 (25 미만) |
| 현재 코드 | `>= 23 && < 25` → 23.0은 과체중 ✓ |

### 5.3 정상체중 하한

- README: 18.5 **초과** → 정상
- 코드: `> 18.5 && < 23` → 18.5는 저체중 ✓

**권장:** 경계값(18.5, 23, 25) 단위 테스트로 기대 동작을 고정한 뒤 코드 수정.

## 9. 결론 및 권장 사항

1. **테스트 우선:** `FAIL()` 제거 후 도메인·경계값 테스트를 먼저 추가하고, 스펙 불일치(BMI=25 등)를 테스트로 확정한다.
2. **작은 단위 리팩토링:** Green 유지하며 `calculateBmi`를 `loadRecords`, `imputeMissingWeights`, `computeBmis`, `aggregateByAgeGroup` 등으로 분리한다.
3. **매직 넘버 제거:** BMI 임계값·type 코드·연령대를 `constexpr` 또는 `enum class`로 치환한다.
4. **데이터 구조 개선:** 24개 `double` 멤버 대신 `std::map` 또는 `AgeGroupStats` 구조체 배열 사용을 검토한다.
5. **예외·엣지 처리:** `ageCount==0`, `height==0`, 파일 오류, 배열 상한을 명시적으로 처리한다.

본 보고서는 **리팩토링·테스트 작성 전 Baseline(Before)** 으로 활용하며, 개선 완료 후 동일 항목으로 Before & After를 비교하는 것을 권장합니다.
